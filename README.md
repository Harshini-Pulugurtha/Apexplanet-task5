# Apexplanet-task5

This project is part of my ApexPlanet Internship – Task 5.

It focuses on building a comprehensive, optimized, and responsive web application as a capstone project — integrating all the skills learned throughout the internship using HTML, CSS, and JavaScript.

🚀 Project Overview

The final project is a fully functional E-Commerce Website designed to provide users with a seamless shopping experience.
It includes product browsing, category filtering, and an interactive cart system while ensuring optimized performance and cross-browser compatibility.

🚀 Features

✔️ E-Commerce Website – Developed a dynamic shopping platform with product listings, add-to-cart functionality, and checkout UI.

✔️ Performance Optimization – Minimized CSS/JS files, applied image lazy loading, and reduced HTTP requests to boost page speed.

✔️ Cross-Browser & Mobile Responsive – Ensured compatibility across Chrome, Firefox, Safari, and mobile browsers.

✔️ Modern UI/UX – Designed an intuitive and visually appealing interface with responsive layouts.

✔️ Capstone Integration – Combined all previous learnings from Tasks 1–4 into one complete project.

🛠️ Technologies Used

HTML5 – Semantic structure and page layout

CSS3 – Styling, layout, animations, and responsive design

JavaScript (ES6) – DOM manipulation, interactivity, and cart management

📂 Project Structure

├── index.html           # Homepage with featured products

├── products.html        # Product listing & filter page

├── cart.html            # Shopping cart and checkout page

├── about.html           #description of the app

├── style.css            # Styling and responsive design

├── script.js            # JavaScript logic for interactivity & optimization

└── README.md            # Documentation
